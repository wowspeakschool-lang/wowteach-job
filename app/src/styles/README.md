# styles

## Откуда взято

`tokens.css` и `__tests__/tokens.test.ts` — **копии** из
`wowspeakschool-lang/wowspeak-platform`, коммит `34d744e`, файлы
`src/styles/tokens.css` и `src/styles/__tests__/tokens.test.ts`.
Скопированы байт-в-байт, чтобы расхождение ловилось обычным `diff`.

Источник истины по дизайн-языку — `DESIGN.md` в том репозитории.
Правки цветов и токенов делаются **там**, сюда переносятся копированием.

> Две копии рано или поздно разъедутся. Когда наберётся третий потребитель,
> имеет смысл вынести токены в отдельный npm-пакет. Пока копия дешевле
> инфраструктуры общего пакета.

## Слои

| Файл | Что это |
|------|---------|
| `tokens.css` | источник истины: `--brand-*`, смысловые токены, тёмная тема, грейды, клубы |
| `global.css` | базовые правила: сброс, фокус, `prefers-reduced-motion` |
| `legacy-hr.css` | совместимость: старые имена переменных из `legacy/hr.html` |
| `legacy-cabinet.css` | то же для `legacy/index.html` |

Правило из DESIGN.md: компоненты берут **только смысловые токены**
(`--surface-*`, `--text-*`, `--accent-*`, `--state-*`). `--brand-*` — для
заливок и крупных элементов, текстом их брать нельзя: в тёмной теме сломается.

## Про legacy-слои

Значения перенесены из боевых файлов **дословно и НЕ темизуются**. Это
осознанно, как и в исходном репозитории: экран, который ещё опирается на
старые имена, в тёмной теме останется светлым — видимый признак того, что
он не перенесён. Файлы сокращаются по мере переноса и удаляются, когда
исчезнет последняя ссылка.

Почему их два: в `hr.html` радиусы `12/20px`, в `index.html` — `14/24px`.
Одним файлом это не покрыть, не изменив одну из версий.
