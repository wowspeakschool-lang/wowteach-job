# legacy — снимок работающей платформы

Здесь лежит копия боевых файлов на момент старта миграции
(коммит `c1f2585`, 18.09.2026). Это **эталон для переноса**, а не рабочий код.

## Правила

- **Не править.** Правки идут в файлы в корне репозитория — именно они
  раздаются GitHub Pages на `job.wowteach.ru`.
- **Не удалять** до полного завершения миграции: на эти файлы сверяется
  каждый перенесённый экран.
- Когда в корне что-то меняется, снимок можно обновить копированием —
  но осознанно, отдельным коммитом, чтобы было видно, что эталон сдвинулся.

## Куда переносим

Новый проект — в каталоге `app/`. Он изолирован: свой `package.json`,
свой Vite root. Сборка из `app/` физически не может перезаписать файлы
в корне репозитория.
